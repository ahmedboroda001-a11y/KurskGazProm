КУРСКГАЗПРОМ · ЗАЯВКИ ЧЕРЕЗ МЕССЕНДЖЕРЫ

1. Распакуйте ZIP.
2. Откройте https://github.com/ahmedboroda001-a11y/KurskGazProm/upload/main
3. Перетащите ВСЕ HTML-файлы и папку assets (с сохранением вложенности).
4. Подтвердите замену файлов и нажмите Commit changes.

ВАЖНО: не переносите файл README_ПЕРЕД_ЗАГРУЗКОЙ.txt, если не хотите хранить инструкцию на GitHub.

Режим работы:
- клиент заполняет поля и выбирает Telegram, WhatsApp либо MAX;
- открывается приложение/веб-страница с текстом заявки;
- клиент проверяет получателя и нажимает «Отправить»;
- сайт не получает статус фактической доставки и не отправляет заявку сам.

WhatsApp и Telegram временно настроены на телефон +7 910 731-02-00. Работа по этим ссылкам зависит от наличия аккаунтов и настроек конфиденциальности. Для надежной отправки в Telegram лучше задать реальный username в assets/config.js.
MAX: без действующей ссылки на бизнес-чат клиент выбирает получателя самостоятельно через официальный интерфейс «Поделиться». Когда появится прямая ссылка MAX, впишите ее в maxChatUrl в assets/config.js.
