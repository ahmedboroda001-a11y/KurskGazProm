# КурскГазПром BLUE — Яндекс Метрика, Вебмастер и Карты

Сайт: https://kurskgazprom.ru/ (публикация и DNS ещё требуют проверки).

## 1. Яндекс Метрика

1. Войдите на https://metrika.yandex.ru/ под Яндекс ID владельца сайта.
2. Создайте счётчик для `kurskgazprom.ru`, региональное время — Москва (UTC+3).
3. Найдите числовой ID счётчика и введите в `assets/config.js` вместо `metrikaId: 0`.
4. Или автоматизированно: `python tools/set_yandex.py --metrika-id 12345678` (12345678 — ПРИМЕР, не реальный ID).
5. Опубликуйте обновлённые файлы GitHub Pages и проверьте посещения в Яндекс Метрике.

В коде уже настроены событийные цели, которые можно создать в интерфейсе Метрики как **Целевое событие**:
- `phone_click`: нажатие на номер телефона;
- `email_click`: нажатие на email;
- `route_click`: переход к построению маршрута;
- `telegram_click`: переход к Telegram-боту (появится после его запуска);
- `calculator_to_lead`: открытие заявки из калькулятора;
- `lead_success`: только после успешного ответа настоящего сервера заявок (не отправляется в демонстрационном режиме).

Вебвизор отключён до отдельного решения по вопросам конфиденциальности.

## 2. Яндекс Вебмастер

1. Откройте https://webmaster.yandex.ru/ и добавьте `https://kurskgazprom.ru`.
2. Выберите подтверждение через метатег. Скопируйте именно код из `content` тега `yandex-verification`.
3. Запустите `python tools/set_yandex.py --webmaster-code ВАШ_КОД` либо разместите предоставленный метатег в `<head>` файла `index.html`.
4. Загрузите изменения на GitHub Pages, нажмите **Подтвердить** в Яндекс Вебмастере.
5. Добавьте ссылку `https://kurskgazprom.ru/sitemap.xml`, проверьте индексацию и ошибки обхода.
6. В Метрике: Настройка → Счётчик → Привязать к Вебмастеру, в Вебмастере подтвердите связь.

До публикации сайта и получения кода подтверждения нельзя считать Вебмастер подключённым.

## 3. Яндекс Карты и построение маршрута

На странице `contacts.html#directions` встроен адресный виджет карты:
https://yandex.ru/map-widget/v1/?ll=36.140706%2C51.745883&z=17&pt=36.140706%2C51.745883%2Cpm2rdl

Кнопка «Проложить маршрут» ведёт в Яндекс Карты:
https://yandex.ru/maps/?mode=routes&rtext=~51.745883%2C36.140706&rtt=auto

Пункт отправления остаётся пустым для определения на стороне Яндекс Карт с разрешения посетителя. Без доступа к геолокации посетителю потребуется выбрать начальную точку самостоятельно.

**Важно**: виджет показывает найденный адрес, но расположение входа/юридически точную метку компании на карте мы пока не подтвердили. После создания карточки компании в Яндекс Бизнес и получения точной точки в Яндекс Картах лучше заменить виджет на официальный embed-код, полученный через «Поделиться → Встроить карту» или Конструктор карт https://yandex.ru/dev/maps/constructor/.

## 4. Что уже сделано в коде

- Карта и контактная карточка на странице контактов, адаптация на мобильных.
- Маршрут на автомобиле и ссылка на адрес Яндекс Карт.

- 6 событийных целей Метрики.
- Верификация Вебмастера: команда настройки добавляет нужный тег в HTML главной (не через JS).
- Sitemap.xml и robots.txt с доменом `kurskgazprom.ru` уже присутствуют.
- Разметка Schema.org LocalBusiness с подтверждённым адресом и временем работы без выдуманных координат.

## 5. Проверки после публикации

1. Откройте главную, контакты, 6 PDF, фотогалерею, калькулятор.
2. Проверьте карту и ссылку маршрута с мобильного телефона в Яндекс Картах.
3. В настройках Метрики проверьте поступление просмотров и цели, учитывая блокировщики рекламы.
4. В Вебмастере проверьте успешное подтверждение прав и sitemap.xml.
5. Важное ограничение: при текущем `apiBase: ''` формы заявок не могут передаваться в Telegram или email. Backend включается отдельно.
