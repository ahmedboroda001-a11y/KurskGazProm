КурскГазПром: облегчённая сборка для GitHub

## Важно про документы

PDF в папке docs для сайта являются визуально сохранёнными, облегчёнными копиями
предоставленных отсканированных документов. Оригиналы (исходные PDF) не изменялись
и должны храниться отдельно у компании. Для юридически значимого обмена используйте оригиналы.

## Загрузка на GitHub

1. Распаковать ZIP на компьютер.
2. Открыть репозиторий KurskGazProm → Add file → Upload files.
3. Перетащить **содержимое** распакованной папки, а не ZIP.
4. Убедиться, что index.html и CNAME в корне.
5. Нажать Commit changes.

Не загружайте пароли, токен бота, OpenAI API-ключ или .env в открытый репозиторий.
