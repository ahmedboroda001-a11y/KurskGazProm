# КурскГазПром BLUE: проверенная сборка

18 HTML-страниц, 6 оригинальных PDF, 10 реальных пользовательских фотографий, SEO-файлы и калькулятор исходных параметров.

## Публикация на GitHub Pages
1. Создайте отдельный репозиторий `KurskGazProm` в GitHub.
2. Загрузите **содержимое** архива, а не сам ZIP, в корень ветки main, включая папки `assets/` и `docs/` и файл `.nojekyll`.
3. В Settings → Pages выберите Deploy from a branch → main → / (root). Дождитесь публикации.
4. Сначала проверьте адрес вида `https://USERNAME.github.io/KurskGazProm/`.
5. Только после проверки прав на `kurskgazprom.ru` добавьте его в Custom domain и настройте DNS согласно настройкам GitHub Pages.
6. `api.kurskgazprom.ru` потребует отдельного HTTPS-сервера для Telegram-бота и заявок. Не размещайте токен бота или ключ OpenAI в GitHub Pages.

## Техническая готовность
- Сайт, меню, услуги, калькулятор, телефоны, почтовые ссылки и оригиналы PDF можно проверить локально.
- Формы не отправляют заявки автоматически, пока не настроен `assets/config.js` и отдельный сервер.
- Бот не запущен без токена BotFather, chat ID администратора и работающего сервера. OpenAI API потребует отдельного ключа и баланса.
- Данные, которых нет: ОГРН, полная юридическая политика, точные адреса/даты/характеристики объектов, тарифы и результаты работ.
- 10 фото предоставлены компанией; часть других дизайнерских изображений остаются иллюстративными.
- Сканы PDF содержат ФИО, подписи и печати: получить согласие на публичное размещение.
- Право на использование названия и домена проверить до публикации.
