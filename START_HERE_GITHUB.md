# КурскГазПром BLUE — публикация на GitHub Pages

1. Создайте публичный репозиторий `KurskGazProm` в GitHub-аккаунте `ahmedboroda001-a11y` (без автоматического README).
2. Распакуйте ZIP и загрузите **содержимое папки** в корень репозитория через **Add file → Upload files**, затем нажмите **Commit changes**.
3. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите **main / (root)** и нажмите **Save**.
4. В **Settings → Pages → Custom domain** укажите `kurskgazprom.ru` и сохраните. В корне проекта уже есть файл CNAME для этого домена. До DNS-настроек убедитесь, что домен принадлежит компании, и рекомендуется подтвердить его владение в GitHub.
5. В личном кабинете DNS-провайдера добавьте для корня (`@`) четыре A-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Для `www` установите CNAME на `ahmedboroda001-a11y.github.io` (без имени репозитория). Не удаляйте и не изменяйте MX/TXT записи почты.
6. Дождитесь применения DNS; проверьте **Enforce HTTPS** в настройках Pages и посетите `https://kurskgazprom.ru`.
7. Проверьте кнопки, маршруты, документы, фотографии и все формы. Для реальной отправки заявок нужен отдельный сервер и настройка `assets/config.js` (не добавляйте туда секреты).
8. Для включения Яндекс Метрики и Вебмастера получите официальные значения `metrikaId` и `yandex-verification`, инструкции в `README_ЯНДЕКС.md`.

**Важно:** сайт статический; Telegram-бот и приём заявок не запускаются на GitHub Pages. Запуск сервера — отдельный этап. Не загружайте API-токены и пароли в репозиторий.
